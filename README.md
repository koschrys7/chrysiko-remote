# Chrysiko Remote

A phone and tablet controller for the **Hotone Ampero II Stomp**, running in the browser over a USB-C cable (Web MIDI).

**Open it:** https://koschrys7.github.io/chrysiko-remote/ · demo without a pedal: https://koschrys7.github.io/chrysiko-remote/?demo

> A personal, unofficial project. Not affiliated with or endorsed by Hotone. Use at your own risk; nothing here saves to the pedal.

## What it does

- **Read** the current preset: the chain (A1–A6 / B1–B6), every block's model and values, all three scenes.
- **See** every block the way it looks:
  - drives, modulation, delays and other effects as compact pedals
  - EQs as response curves
  - amps as panels, cabs as cabinets
- **Live control** (off until you switch it on):
  - scenes
  - any knob, including EQ bands with frequency, gain and Q drag handles, pinch and steppers
  - block on/off: tap the pedal's pad
  - patch select: bank, patch, patch −/+
  - patch volume, tuner, tap tempo
- **Read-back:**
  - Every change is read back from the pedal and marked ✓ or ⚠.
  - «Επαναφορά αλλαγών» (revert changes) sends the original values back.
  - Changes stay in the pedal's live buffer and are never saved.

## Use it on an iPhone or iPad

1. Install **Web MIDI Browser** from the App Store. Safari and the other iOS browsers have no Web MIDI.
2. Connect the iPhone (USB-C) or iPad to the Ampero's USB-C port.
3. Open the link above in Web MIDI Browser, then tap **Σύνδεση** (connect) and **Διάβασε το preset** (read the preset).
4. Switch on **Live** to control the pedal.

On a Mac, Chrome or Edge also work.

## How it talks to the pedal

| Function | Message |
|---|---|
| Read preset / scene / parameter | Ampero normal-mode SysEx `0x01000000`, `0x03000001`, `0x01040003`. Replies flagged `0x12` are LZO1X streams. |
| Set parameter / select scene | SysEx `0x01040003` (`slot u16, param u16, float32`), `0x03000001` (`u8`) |
| Patch select, patch volume, block on/off, tuner, tap | MIDI CC/PC from Hotone's MIDI Control Information List: CC0 + PC, CC7, CC48–59, CC60, CC76 |

`ampero.js` can encode only these. Save, model, routing and every other command are refused. The SysEx framing follows the editor's native host encoder; the parameter, scene and other command layouts follow the public [codex4ampero](https://github.com/fantacyfromsjtu/codex4ampero) notes.

## Files

- `index.html` (layout and styles), `app.js` (page logic), `ampero.js` (protocol), `views.js` (drawings).
- `catalog.js`: model and parameter names, generated by `tools/build_catalog.py` from the editor's catalogue.
- `fonts/`: Inter, SIL OFL.
- `tools/build_single.py`: bundles everything into one HTML file.
- `test/`: `node test/protocol_test.mjs` and `node test/decode_test.mjs test/capture-trad-violin.json test/reference-trad-violin.json` replay a real capture.
